Create `src/components/WatchSuggestionsView.tsx` following the Warm Archival Folio aesthetic (`#F6F1E7`, `#EFE8DA`, `#FBF8F2`, `#171412`, `#B8292F`, `#234B6E`, `#6B3A6E`, `#2A6B53`):
1. **Header & Discovery Mode Bar**:
   - Displays active discovery summary (e.g., *"Tailored from 3 Watched Titles & 2 Genre/Theme Filters"* or *"Curated Genre & Category Discovery"*).
   - Quick toggle for **"Hide Already Watched (`watchedIds.size`)"** vs. **"Show All"**, **Region Selector (`AU`, `US`, `UK`)**, and **"Fetch Live Suggestions"** button to pull new matching titles from TMDB/live catalog into the archive.
2. **Section 1: "Based on What You've Watched" (Interactive Seed Shelf)**:
   - Shows currently marked **Watched Titles** (with poster thumbnail, title, year, and remove `×` button) plus a quick **"+ Add Title You've Watched"** search combobox (searching both the local graph and live worldwide catalog so users can pick *any* movie/show they've watched even if it wasn't in the seed graph yet!).
   - Includes quick one-click starter chips if the user hasn't marked any watched titles yet (e.g., *Inception*, *Severance*, *Dark*, *Interstellar*, *The Prestige*, *Blade Runner 2049*, *Arrival*, *Black Mirror*, *Oppenheimer*, *True Detective*).
3. **Section 2: "Browse by Genre, Category & Mood" (Multi-Facet Filter Deck)**:
   - **Curated Category Cards / Pills** (`CURATED_CATEGORIES`):
     - *All Categories*, *Mind-Bending Sci-Fi*, *Critics' Darlings (RT 90%+)*, *Audience Favorites (IMDb 8.5+)*, *Slow-Burn Mystery Series*, *High-Tension Thrillers*, *Auteur Masterworks*, *Cyberpunk & AI*, *Time & Memory Puzzles*.
   - **Broad Genre Chips** (extracted dynamically from catalog + standard genres: *Sci-Fi*, *Thriller*, *Mystery*, *Drama*, *Crime*, *Action*, *Fantasy*, *Adventure*, *Comedy*, *Animation*) with multi-select support.
   - **Specific Narrative Themes / Tropes Chips** (e.g., *Time Loop*, *Simulated Reality*, *Heist / Infiltration*, *Memory Erasure*, *AI Consciousness*, *Psychological Labyrinth*, *Quantum Multiverse*).
   - **Refinement Bar**:
     - Media Format (`All`, `Feature Films`, `TV Series`)
     - Collaborator / Creator filter dropdown (Directors, Lead Actors, Composers)
     - Release Era (`All Eras`, `2020s`, `2010s`, `2000s`, `Pre-2000 Classics`)
     - Minimum IMDb Rating filter (`Any`, `7.5+`, `8.0+`, `8.5+`)
     - Streaming Provider filter (`All Providers`, `Streamable Now in Region`, or specific service like `Netflix`, `Apple TV+`, `Prime Video`, `Max`, `Stan`, `Binge`, `Disney+`).
4. **Section 3: Ranked Watch Suggestion Cards Grid/Ledger**:
   - Each suggestion card presents:
     - Rank badge (`#01`, `#02`...), 2:3 Poster artwork, Media Type badge (`Film` / `Series`), Title, Year, Director/Creator, Runtime/Seasons, Content Rating.
     - **Match Score Badge** (`94% Match`) + Ratings Trio (`IMDb ★`, `RT %`, `Metascore`).
     - **"Because You Watched..." Banner**: Highlights which of the user's watched titles triggered this recommendation and why (e.g., *"Because you watched Inception & Severance"*).
     - **Shared Craft, Theme & Genre Reason Pills**: Interactive pills (`Theme: Memory Erasure`, `Director: Christopher Nolan`, `Genre: Sci-Fi · Thriller`, `Score: Hans Zimmer`).
     - **Where to Watch in Region (`AU`/`US`/`UK`)**: Direct streaming badges (`Netflix`, `Apple TV+`, `Prime Video`, etc.).
     - **Card Actions**:
       - `Mark Watched` / `Watched ✓` (adds to watched list and immediately updates recommendations)
       - `Inspect Notes` (opens in `RightInspectorCard`)
       - `View in 3D Map` (centers or orbits the title in `3D Constellation` view)
       - `More Like This` (sets this title as a seed to pivot recommendations)
