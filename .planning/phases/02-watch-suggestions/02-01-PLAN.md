  <name>Task 1: Extend Types & Create Multi-Criteria Watch Suggestion Engine (`src/lib/types.ts` & `src/lib/recommendations.ts`)</name>
  <files>src/lib/types.ts, src/lib/recommendations.ts</files>
  <Reversibility>trivial</Reversibility>
  <action>
1. In `src/lib/types.ts`:
   - Extend `ViewMode` to `'2D' | '3D' | 'MATRIX' | 'SUGGEST'`.
   - Add types for the suggestion system:
     - `SuggestionMode`: `'WATCHED_SEEDS' | 'GENRE_CATEGORY' | 'COMBINED'`
     - `CuratedCategoryId`: `'ALL' | 'MIND_BENDING' | 'CRITICS_DARLINGS' | 'HIGH_AUDIENCE' | 'SLOW_BURN_SERIES' | 'FAST_PACED_THRILLERS' | 'AUTEUR_MASTERWORKS' | 'CYBERPUNK_AI' | 'TIME_AND_MEMORY'`
     - `DecadeFilter`: `'ALL' | '2020s' | '2010s' | '2000s' | 'CLASSIC'`
     - `SuggestionFilterState`:
       - `seedMediaIds: string[]` (specific watched/seed titles active for recommendation)
       - `selectedGenres: string[]` (broad genres e.g. `Sci-Fi`, `Thriller`, `Mystery`, `Drama`, `Crime`, `Action`, `Fantasy`)
       - `selectedTropes: string[]` (specific narrative themes/tropes)
       - `selectedCollaborator: string | null` (Director, Actor, or Composer filter)
       - `curatedCategory: CuratedCategoryId`
       - `mediaFilter: 'ALL' | 'MOVIE' | 'TV'`
       - `decadeFilter: DecadeFilter`
       - `minImdbRating: number`
       - `streamingOnlyInRegion: boolean`
       - `selectedProvider: string | null`
       - `hideWatched: boolean`
       - `preset: GravityPreset`
     - `SuggestionReason`: `{ id: string; label: string; type: 'BECAUSE_WATCHED' | 'GENRE' | 'TROPE' | 'AUTEUR' | 'CAST' | 'SCORE' | 'CATEGORY' | 'ACCLAIM'; color: string; points: number; entityNodeId?: string }`
     - `WatchSuggestion`:
       - `item: MediaItem`
       - `matchScore: number` (0–99%)
       - `becauseYouWatched: Array<{ id: string; title: string; year: number; pairScore: number; topShared: string[] }>`
       - `reasons: SuggestionReason[]`
       - `matchedGenres: string[]`
       - `matchedTropes: string[]`
2. Create `src/lib/recommendations.ts`:
   - Define `CURATED_CATEGORIES` with rich metadata (id, label, subtitle, icon key, matching logic for genres/tropes/ratings/mediaType).
   - Implement `extractCatalogFacets(items: MediaItem[], region: RegionCode)` returning sorted lists with counts for:
     - `genres` (combining `primaryGenre` and `genres`)
     - `tropes` (specific narrative themes)
     - `collaborators` (top Directors, Actors, Composers)
     - `providers` (streaming providers available in `region`)
   - Implement `computeWatchSuggestions(items: MediaItem[], watchedIds: Set<string>, filters: SuggestionFilterState, region: RegionCode): WatchSuggestion[]`:
     - Filters candidates by `hideWatched` (excluding `watchedIds` and `filters.seedMediaIds`), `mediaFilter`, `decadeFilter`, `minImdbRating`, `streamingOnlyInRegion`, `selectedProvider`, `selectedCollaborator`, and `curatedCategory`.
     - If `selectedGenres.length > 0`, requires or strongly boosts candidates matching selected genres (`+18 pts` primary genre match, `+12 pts` per matched genre).
     - If `selectedTropes.length > 0`, boosts candidates matching selected narrative themes (`+16 pts` per matched trope).
     - If active seed titles exist (`filters.seedMediaIds.length > 0` or `watchedIds.size > 0`):
       - Computes pairwise similarity against each watched/seed title using `calculateSimilarity` PLUS genre kinship (`+8 pts` shared primary genre, `+5 pts` per shared secondary genre) and co-watch overlap (`+6 pts`).
       - Records `becauseYouWatched` attributions for the top contributing watched titles (e.g., *"Because you watched Inception (2010) & Dark (2017)"*) and aggregates concrete shared connections (`Director`, `Starring`, `Theme`, `Score`, `Genre`).
     - When browsing purely by Genre / Category without seed titles, ranks matching titles by category/genre fit + critical consensus (`imdbRating`, `rottenTomatoes`, `metascore`) and generates clear `SuggestionReason` pills.
  </action>
