  <name>Task 1: Add UserProfile & GraphScopeMode Types and Personal Watched Graph Engine (`src/lib/types.ts` & `src/lib/similarity.ts`)</name>
  <files>src/lib/types.ts, src/lib/similarity.ts</files>
  <Reversibility>trivial</Reversibility>
  <action>
1. In `src/lib/types.ts`:
   - Add `export type GraphScopeMode = 'FULL_ARCHIVE' | 'WATCHED_ONLY' | 'WATCHED_PLUS_SUGGESTIONS';`
   - Add `isWatched?: boolean;` and `isSuggested?: boolean;` to `GraphNode`.
   - Define `UserProfile`:
     ```ts
     export interface UserProfile {
       id: string;
       handle: string;
       displayName: string;
       email?: string;
       bio?: string;
       avatarColor: string;
       watchedIds: string[];
       watchedCustomItems: MediaItem[];
       preferredRegion: RegionCode;
       defaultPreset: GravityPreset;
       defaultGraphScope: GraphScopeMode;
       createdAt: string;
       updatedAt: string;
     }
     ```
2. In `src/lib/similarity.ts`:
   - Extend `BuildGraphOptions` with:
     - `graphScope?: GraphScopeMode;`
     - `watchedIds?: string[];`
     - `suggestedMediaIds?: string[];`
   - In `buildSpatialGraph`:
     - Build `watchedSet = new Set(watchedIds || [])` and `suggestedSet = new Set(suggestedMediaIds || [])`.
     - When `graphScope === 'WATCHED_ONLY'`:
       - Filter `items` in global constellation mode so only titles in `watchedSet` (or `focalItem` if locked) are included in `filteredMedia`.
       - Because a user's personal watched list may be smaller (e.g. 2–30 titles) and more eclectic than the 100+ title archive, use a more inclusive effective threshold (`Math.min(12, forceSettings.matchThreshold)`) and, when two watched titles share a primary/secondary genre (`itemA.genres.some(g => itemB.genres.includes(g))`) even without a concrete auteur/cast/trope overlap, synthesize a lightweight `Genre Kinship` connection (`+12 pts`) in personal graph mode so the user's watched titles still weave into a connected personal constellation rather than floating completely unlinked.
       - Furthermore, in `WATCHED_ONLY` / `WATCHED_PLUS_SUGGESTIONS` mode, allow shared entity bridge nodes (`DIRECTOR`, `ACTOR`, `TROPE`, `COMPOSER`) whenever `ent.mediaIds.size >= 2` across the active personal graph items regardless of pairwise threshold, so every shared director, actor, composer, or theme between any two watched titles is guaranteed to appear as a bridge node!
     - When `graphScope === 'WATCHED_PLUS_SUGGESTIONS'`:
       - Filter `items` to include all titles in `watchedSet` PLUS titles in `suggestedSet`.
       - Annotate each `GraphNode` with `isWatched: watchedSet.has(item.id)` and `isSuggested: !watchedSet.has(item.id) && suggestedSet.has(item.id)`.
     - Always set `isWatched: watchedSet.has(item.id)` on media `GraphNode`s across all scopes so 3D/2D views and inspectors know whether a node has been watched by the active user.
  </action>
